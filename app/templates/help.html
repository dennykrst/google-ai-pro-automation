Alur per akun

Satu akun dijalankan berurutan oleh satu proses terpisah. Setiap langkah diperiksa dulu sebelum menekan tombol apa pun — kalau angka di layar tidak sesuai harapan, alur berhenti daripada menagih sesuatu yang salah.

#HandlerYang dilakukanGuard sebelum lanjut
0 egress Cek IP dan negara lewat ipwho.is di dalam browser. Negara harus US; menunggu sampai 120 detik lalu berhenti.
1 login Email → password → TOTP, termasuk layar yang tidak bisa diprediksi (captcha, prompt pemulihan, device prompt). URL harus keluar dari accounts.google.com.
2 discover Baca tanggal akhir langganan dari dialog cancel (tanpa konfirmasi), lalu tentukan layer yang tersisa. 0 bln → layer 1 · 12 → layer 2 · 18 → layer 3 · 24 → layer 4 sekali.
3 bind card Kalau dialog meminta metode bayar: klik Add card, isi nomor, kedaluwarsa, CVC, nama, ZIP, lalu simpan. Tiap kolom dibaca ulang; nilai yang tidak cocok diketik ulang.
4 layer 1 Buka dialog penawaran, baca total, tekan Subscribe. $0.00 atau label 12-month free trial.
5 layer 2 Upgrade ke paket 18 bulan. Tanggal akhir ±18 bulan dari hari ini (selisih maksimal 1 hari).
6 layer 3 Upgrade ke paket 24 bulan. Tanggal akhir ±24 bulan.
7 cancel Play → Manage → Cancel subscription → konfirmasi. Status harus Canceled + tanggal berakhir terbaca.
8 detach card Hapus kartu dari profil pembayaran akun; kartu tetap tersimpan di vault untuk akun berikutnya. Best effort — butuh persetujuan di HP, ditunggu sampai 300 detik.

Kolom step di tabel akun adalah nomor handler terakhir yang dijalankan — 1–4 untuk layer, angka lebih besar untuk tahap berikutnya.

Format input

Satu baris per item; pemisah boleh |, koma, titik koma, tab, atau spasi.

  • Kartu: nomor|MM/YY|CVC — contoh 4111111111111111|08/29|123. Nomor dan CVC masuk secrets.json; yang ditampilkan hanya 4 digit terakhir.
  • Akun: email|password|seed_totp — seed boleh kosong kalau akun tanpa 2FA. Seed dinormalisasi (spasi/huruf besar diabaikan).

Kartu dipakai bergilir: akun baru memakai kartu aktif yang paling lama tidak dipakai. Tandai kartu mati kalau sudah tidak layak.

Panel akun

  • cari email / filter status — menyaring baris yang tampil, tanpa menyentuh data. Filter tetap aktif saat status akun berubah.
  • jalankan terpilih — centang beberapa baris (atau centang header untuk semua), lalu jalankan sekaligus. Masuk antrean serial yang sama dengan jalankan semua.
  • log (per baris) — riwayat 5 run terakhir untuk akun itu: waktu mulai, status, egress, ringkasan penyebab gagal, jumlah screenshot, dan tombol lihat log untuk membaca run mana pun. Riwayat disimpan di tabel runs/artifacts, bukan cuma nama file.
  • berakhir — tanggal akhir langganan yang terbaca saat discovery atau cancel. — berarti belum pernah terbaca.
  • 8 titik di kolom status — langkah handler 1–8; titik hijau adalah langkah terakhir yang dikerjakan.

Yang butuh tangan manusia

  • Device prompt saat login — Google minta konfirmasi di HP. Alur menunggu sampai 5 menit (tidak dihitung sebagai langkah gagal).
  • Persetujuan hapus kartu — halaman pembayaran hanya menawarkan "tap Yes on your phone". Alur mengirim permintaan lalu menunggu 300 detik.
  • reCAPTCHA gambar — checkbox diklik otomatis; kalau Google naik ke teka-teki gambar, selesaikan di jendela Chrome yang terbuka.

Kalau keduanya tidak disetujui, langganan tetap aktif dan cancel tetap berjalan — hanya kartu yang tertinggal di akun.

Kalau gagal: baca baris ini di log

Penanda di logArtinyaYang bisa dilakukan
EGRESS … ≠ US Egress bukan US. Nyalakan VPN US, jalankan ulang.
LOGIN GAGAL Login tidak selesai (password/TOTP/captcha). Selesaikan manual di jendela Chrome, atau perbaiki password/seed di vault.
kolom CVC meleset Isi kolom tidak sama dengan yang diketik (autofill ikut masuk). Alur mengulang sendiri; kalau menetap, hapus profil Chrome akun itu.
tombol Add card tidak ditemukan Dialog belum menampilkan form kartu. Run ulang; kalau terus terjadi, cek screenshot flow_L*.png.
Google menolak: Something went wrong Google menutup jalur upgrade (biasanya batas 24 bulan). Normal untuk layer 4; alur lanjut ke cancel.
cancel terverifikasi Status Canceled dan tanggal berakhir terbaca. Tidak ada — akun selesai.

Data & privasi

Semua data hidup di data dir, tidak ada telemetri dan tidak ada panggilan ke server selain Google (dan ipwho.is untuk cek negara):

{{ data_dir }}

  • db.sqlite3 — metadata akun/kartu (tanpa nomor kartu/CVC).
  • secrets.json — password, seed TOTP, nomor kartu, CVC (0600).
  • console.token — token akses konsol.
  • profiles/ — profil Chrome per akun (cookie login).
  • artifacts/ — log run dan screenshot tiap layer.
Jangan commit isi data dir. secrets.json memuat kredensial dalam bentuk yang bisa dibaca siapa pun yang bisa membuka file itu — perlindungannya izin file (0600 di direktori 0700), bukan Keychain.
