What this app does

It drives a real Chrome window through the whole Google AI Pro offer for one account at a time, and it never commits anything it has not checked on screen first. Accounts run one after another in a queue, each in its own process, so a stuck browser cannot take the console down with it.

The short version: log in, bind a card when Google asks for one, take the three stacked offers, confirm the end date after every step, cancel the renewal, then take the card back off the account.

The flow, step by step

#HandlerWhat happensCheck before moving on
0 egress Loads a small IP service inside the browser to see where traffic comes from. Country must be US; waits up to 120 s, then stops.
1 login Email, password, TOTP — plus whatever screen Google puts in between (captcha, recovery prompt, device prompt). URL has left accounts.google.com.
2 discover Reads the current end date from the cancel dialog without confirming anything, then decides which offers are still available. 0 months → offer 1 · 12 → offer 2 · 18 → offer 3 · 24 → try offer 4 once.
3 bind card If the dialog asks for a payment method: Add card → number, expiry, CVC, holder, ZIP → Save. Every field is read back; a value that did not stick is typed again.
4 offer 1 Opens the offer dialog, reads the total, presses Subscribe. $0.00 or the 12-month trial label.
5 offer 2 Upgrades to the 18-month term. End date lands within a day of +18 months.
6 offer 3 Upgrades to the 24-month term. End date lands within a day of +24 months.
7 cancel Play → Manage → Cancel subscription → confirm. Status reads Canceled and the end date is visible.
8 detach card Removes the card from the account's payment profile. The card stays in the vault for the next account. Best effort — needs your approval on the phone, waited up to 300 s.

Input formats

One item per line. Separators can be |, comma, semicolon, tab or spaces.

  • Card: number|MM/YY|CVC — for example 4111111111111111|08/29|123. Number and CVC go into the local store; the screen only ever shows the last four digits.
  • Account: email|password|totp-secret. Leave the secret out for accounts without 2FA; spaces and lower case in the secret are fine.

Cards are shared on rotation: a new account takes the active card that has gone longest unused. Disable a card once it stops working — accounts using it get released.

The accounts panel

  • search / status filter — narrows the table only; it keeps applying while statuses change.
  • run selected — tick a few rows (or the header checkbox for all) and queue them at once. Same serial queue as run all.
  • log per row — the last five runs for that account: start time, status, egress, why it failed, how many screenshots, and a show log button for any of them. The history is stored in the database, not just in file names.
  • ends — the end date read during discovery or cancel. — means it has not been read yet.
  • eight dots next to the status — the handler step; the green dot is the last one that ran.

Still needs a human

  • Device prompt at login — Google asks you to confirm on your phone. The run waits up to five minutes without counting it as a failure.
  • Removing the card — the payments page only offers "tap Yes on your phone". The run sends the request and waits up to 300 seconds.
  • Image captcha — the checkbox is clicked automatically; if Google escalates to a picture puzzle, solve it in the Chrome window.

If you skip either approval, the subscription stays active and the cancel still runs — only the card is left on the account.

When it fails: read this line in the log

MarkerMeaningWhat to do
EGRESS … ≠ US Traffic is not US. Turn the US VPN on and run again.
LOGIN GAGAL Login did not finish (password, TOTP or captcha). Finish it by hand in the Chrome window, or fix the password/secret in the vault.
kolom CVC meleset A field did not keep what was typed (browser autofill won). The run retries by itself; if it persists, clear that account's Chrome profile.
tombol Add card tidak ditemukan The dialog never rendered the card form. Run again; check the flow_L*.png screenshot if it repeats.
Something went wrong Google closed the upgrade path (usually the 24-month cap). Normal for offer 4; the run continues to cancel.
cancel terverifikasi Status Canceled and the end date were both read. Nothing — the account is done.

Data & privacy

Everything lives in the data dir. No telemetry, and no outbound calls beyond Google and ipwho.is (the country check):

{{ data_dir }}

  • db.sqlite3 — account and card metadata (no card number, no CVC).
  • secrets.json — passwords, TOTP secrets, card numbers, CVC (mode 0600).
  • console.token — access token. Only used when the console is opened beyond loopback (GAI_ALLOW_REMOTE=1) or with GAI_REQUIRE_TOKEN=1; normally you just open http://127.0.0.1:8765/.
  • profiles/ — one Chrome profile per account (login cookies).
  • artifacts/ — run logs and per-offer screenshots.
Never commit the data dir. secrets.json holds credentials in a form anyone who can read the file can use — the protection is file permissions (0600 inside a 0700 directory), not a system keychain.
